Описание программы

Программа управляет движением робота на поле 100х100. Робот начинает движение из точки (1,1). Пользователь может:

  1. Задать прямоугольные запретные зоны
  2. Написать программу движения на высокоуровневых командах
  3. Получить траекторию в виде списка координат
