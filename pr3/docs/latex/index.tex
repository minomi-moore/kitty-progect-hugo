\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Описание программы}{Описание программы}}\label{index_autotoc_md2}
Программа управляет движением робота на {\bfseries{поле 100х100}}. Робот начинает движение из точки (1,1). Пользователь может\+:


\begin{DoxyEnumerate}
\item Задать прямоугольные запретные зоны
\item Написать программу движения на высокоуровневых командах
\item Получить траекторию в виде списка координат
\end{DoxyEnumerate}
