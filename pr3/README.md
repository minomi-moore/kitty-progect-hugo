## Описание программы

Программа управляет движением робота на **поле 100х100**.
Робот начинает движение из точки (1,1). Пользователь может:

1. Задать прямоугольные запретные зоны
2. Написать программу движения на высокоуровневых командах
3. Получить траекторию в виде списка координат

---

## Структура кода

| Функция | Назначение |
|---------|------------|
| `post_zapret` | Формирование списка точек запретной зоны |
| `zapret_zona` | Ввод всех запретных зон |
| `prov` | Проверка столкновений |
| `gran` | Проверка границ поля |
| `count_b` | Очистка лишних команд B |
| `high_level` | Ввод высокоуровневых команд |
| `low_level` | Генерация траектории |
